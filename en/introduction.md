# CSSGen Introduction

Welcome to CSSGen! This is a powerful CSS style generator, designed specifically for live streaming platforms.

## What is CSSGen?

CSSGen is a visual CSS style editor that allows you to:

- 🎨 **Visual Editing** - Adjust styles in real-time through a user-friendly interface
- 🔄 **Real-Time Preview** - See-what-you-get editing experience
- 💾 **Style Management** - Save and manage your custom styles
- 🌍 **Multi-Platform Support** - Supports Bilibili, YouTube, and other live streaming platforms

## Main Features

### 1. Rich Style Options

CSSGen provides comprehensive CSS property editing capabilities:

- **Text Styles**: Font, size, color, shadow, etc.
- **Background Styles**: Color, image, gradient, etc.
- **Border Styles**: Width, color, radius, shadow, etc.
- **Layout Styles**: Display, Flex layout, etc.

### 2. Component-Based Architecture

Each CSS property is encapsulated into independent components, making it easier to:
- Modular development
- Code reuse
- Maintenance and extension

### 3. User-Friendly

- Intuitive user interface
- Real-time style preview
- Simple import and export functionality

## Quick Start

1. Select the element to edit
2. Adjust styles in the right panel
3. Real-time preview the effect
4. Save or export your styles
