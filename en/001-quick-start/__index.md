# Start Using CSSGen Editor

Welcome to CSSGen Editor! This guide will help you get started quickly, creating your first chat style project in just a few minutes.

## Usage Flow

The basic usage flow of CSSGen Editor is as follows:

1. **Login/Registration** - Create your CSSGen account and login
2. **Create Project** - Create a new project for your chat style
3. **Configure Style** - Use the visual editor to configure the chat style
4. **Data Management** - Manage your style data or export for use
5. **Use Style** - Use the exported style in the corresponding software

## Prerequisites

Before starting, please ensure you have met the following requirements:

### Account Requirements

CSSGen is managed based on login status, you need to:

- ✅ Have an account (if you don't have one, please <a href="/signup">register an account</a> first)
- ✅ Successfully login to the system

### Browser Requirements

CSSGen is based on browser operation, and promises to support the following browsers:

- **Chrome** - Recommended to use the latest version
- **Safari** - Recommended to use the latest version
- **Edge** (Chromium kernel) - Recommended to use the latest version

> ⚠️ **Note**: Using in other browsers may cause compatibility issues, we strongly recommend you to use the latest version of the above browsers for the best experience.

### Network Requirements

- Stable network connection (for cloud synchronization and resource loading)
