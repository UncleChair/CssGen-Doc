# Style Component Guide

This section contains the detailed explanation of all style components provided by the CSSGen editor.

## Style Categories

The CSSGen editor categorizes style components into the following two main categories:

### 📝 Normal Component

All components under the general setting are called `normal components`, they provide a series of preset quick actions, which can conveniently perform some general configuration and common operations, but generally have limited usage and adjustment range.

### 📐 Advanced Component

Components that can be added in the layer under advanced settings are called `advanced components`. They provide most of the components organized by CSS properties. Using them may require some basic CSS knowledge, but they offer more comprehensive functionality with no usage restrictions.

> If you are interested in learning some basic CSS knowledge, you can visit <a href="https://developer.mozilla.org/zh-CN/docs/Web/CSS" target="_blank"> MDN documentation</a> for more information.

You can first learn how to use the normal components, which can solve most simple style requirements; if your requirements are more complex, then try to understand the usage of advanced components. Or throw all the questions to AI, try [intelligent mode](./agent-mode).
