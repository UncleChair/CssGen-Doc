# Opacity Style Component

_Adjust the opacity of the layer._

<!-- demo:opacity-editor -->

> The **Force Usage** option can be used to force override the style settings when the style adjustment is not functional on some platforms.

## Number Adjustment

Opacity adjustment can be set by dragging the slider, the supported range is 0 to 100, 0 represents completely transparent and 100 represents completely opaque.
