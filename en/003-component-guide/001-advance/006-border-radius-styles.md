# Border Radius Style Component

_Add a rounded corner effect to the four corners of the layer._

<!-- demo:border-radius-editor -->

> The **Force Usage** option can be used to force override the style settings when the style adjustment is not functional on some platforms.

The border radius style component currently only supports the `px`<sup><a href="#ref1">[1]</a></sup> unit.

## Overall Adjustment

In overall mode, you can set the radius of the four corners at the same time, the number part can be input directly or dragged with the slider, only positive numbers are supported.

## Single Side Adjustment

In detailed adjustment mode, you can set the radius of the four corners separately, the supported numbers and units are the same as in overall adjustment mode.

## **Reference**

<span id="ref1">[1]</span> [MDN length unit px](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/length#px)
