# Advance Component

Advance component provides rich style customization features, allowing you to adjust the details of the layer style. This guide will help you understand all available advanced components and their usage.

## 📐 Layout and Size

The following components are used to control the boundary, spacing, and size of the layer.

### [Border](./border-styles)
Add a border to the layer, support line border and image border modes, you can customize the border style, width, color and other properties.

### [Border Radius](./border-radius-styles)
Add a rounded corner effect to the layer, support overall adjustment or single adjustment of the corner radius of four corners.

## 🎨 Visual Effects

The following components are used to create various visual effects, improve the beauty of the interface.

### [Opacity](./opacity-styles)
Control the overall transparency of the layer, the range is from completely transparent to completely opaque.

## ✍️ Text Style

The following components are used to control the display effect of text in the layer.

### [Font](./font-styles)
Control the text attributes, including font, size, color, alignment, thickness, spacing, decoration and outline.

## 🔧 Advanced Features

The following components provide more complex and flexible style control capabilities.

### [Position](./position-styles)
Use CSS positioning attributes to control the position of the layer on the page, support multiple positioning modes.

### [Display](./display-styles)
Control the display mode and layout mode of the layer, such as block, inline, flex layout, etc.

### [Custom Code](./custom-styles)
Add any custom CSS code, implement advanced styles or special effects that the editor does not directly support.

### [Attached Layer](./pseudo-element)
Add an attached layer in the front or behind the layer, commonly used to add decorative elements or additional content.
---

## 💡 Advice

- **Start from the basics**: First master the components related to layout and size, they are the foundation of building the interface.
- **Progressive**: After familiarizing yourself with the basic components, try the visual effects and advanced features.
- **Reasonable use**: Not all components need to be used on each layer, select the appropriate components according to the actual needs.

> 💡 Tip: Most components provide an **Force Usage** option, which can be used to force override the style settings when the style adjustment is invalid on some platforms.
