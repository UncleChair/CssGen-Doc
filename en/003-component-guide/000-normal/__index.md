# Normal Component

In the normal setting options, you can see many options, they are similar in many functions except for the name. Therefore, according to the function, the CSS editor divides these options into:

- [Layout Component](./layout-component)
- [Avatar Component](./avatar-component)
- [Basic Component](./basic-component)

Layout component can perform simple layer display adjustment, layout control, and default font setting.

Avatar component is generally used to set user avatar and avatar border, you can quickly adjust the avatar size or add image border.

Basic component will set the border and background color of the selected area, generally used to adjust the basic text display area.

By combining the normal components, most simple style requirements can be satisfied.
