# Basic Component

_Basic component corresponds to the text content and other options in the normal settings_

Basic component is used to set the border and background color of the selected area, you can quickly beautify the selected layer.

<!-- demo:message-type-selector -->

You can try the effect of different options below.

<!-- demo:text-element-demo -->

- **Border Setting**: Used to set the border style of the layer, the function is consistent with the [Border Styles Component](./border-styles).
    - **Normal Mode**: Set basic line border.
    - **Advanced Mode**: Add image as border.
- **Background Color**: Used to set the basic background color of the layer.
