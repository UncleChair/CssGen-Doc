# Avatar Component

_Avatar component corresponds to the author photo option in the normal settings_

Avatar component is used to set the appearance of the user avatar, you can quickly adjust the avatar size or add decorative border to the avatar.

<!-- demo:message-type-selector -->

You can try the effect of different options below.

<!-- demo:avatar-demo -->

- **Image Setting**: Used to set some basic properties of the user avatar image.
- **Border Setting**: Used to add a border to the user avatar image.
