# Introduction

Learn about CSSGen, how to create a style from scratch, browse reference examples, interactive examples, and more information.

## What is CSSGen Editor?

CSSGen Editor is a powerful CSS style generation tool that allows you to:

- 🌐 **Online Editing** - No need to download or install, edit and preview styles anytime, anywhere
- 🎨 **Visual Operations** - Adjust styles in real-time through a friendly interface
- 🔄 **Real-time Preview** - Edit as you see, what you get
- 🏭 **Style Generation** - Generate styles that can be used directly
- 🎯 **Multi-platform Support** - Support multiple live streaming platforms, including Bilibili, YouTube, Twitch, and more

## Quick Start

In the [Quick Start](./quick-start) section, we have prepared many examples and specific operations to help you quickly implement your needs. You can also refer to the advanced content in [Component Guide](./component-guide) to learn more about advanced features.

## Why Choose CSSGen Editor?

CSSGen Editor is an easy-to-use CSS style editor designed for designers and end users, allowing you to create various styles without requiring much related professional knowledge.

### Basic Free

The core editing features of CSSGen Editor are free to use, allowing you to edit and preview styles anytime, anywhere. At the current stage, the cloud storage related features are free to use, and after the official version is released, the free usage range will be narrowed down and charged in stages to maintain server costs.

### Feature Complete

CSSGen Editor provides a rich set of features, including:
- Text Styles
- Background Styles
- Border Styles
...

and more style components, you can freely combine these components to create various styles.

### Multi-platform Support

CSSGen Editor supports:
- BiliBili - BliveChat@Original
- BiliBili - BliveChat@KUMA Modified DOM
- YouTube - YouTube Web (Not yet open)
- Twitch - Twitch Web (Not yet open)

and more live streaming platforms, and we will continue to add more supported content, you can easily select the platform and create various styles.
