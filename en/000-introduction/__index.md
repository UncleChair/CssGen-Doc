# Introduction

Learn about what CSSGen is, how to create styles from scratch, browse reference cases, interactive examples, and more information.

## What is CSSGen Editor?

CSSGen Editor is a powerful CSS style generation tool that allows you to:

- 🌐 **Online Editing** - Edit anytime, anywhere without downloading and installing
- 🎨 **Visual Operation** - Adjust styles in real time through a friendly interface
- 🔄 **Real-time Preview** - Edit as you see it
- 🏭 **Style Generation** - Generate styles that can be used directly
- 🎯 **Multi-platform Support** - Support multiple live streaming platforms including Bilibili, YouTube, and more

## Quick Start

In the [Quick Start](./quick-start) section, we have prepared many examples and specific operations to help you quickly achieve your needs. You can also refer to the advanced content in [Component Guide](./component-guide) to learn more about advanced features.

## Why Choose CSSGen Editor?

CSSGen Editor is an easy-to-use CSS style editor designed for designers and end users, allowing you to create various styles without requiring a lot of related professional knowledge.

### Basic Free

CSSGen Editor's core editing features are free to use, allowing you to edit and preview styles anytime, anywhere. At the current stage, cloud storage-related features are free to use. After the official version is released, the free usage range will be narrowed and charged in stages to maintain server costs.

### Rich Features

CSSGen Editor provides rich features, including:
- Text Styles
- Background Styles
- Border Styles
...

and so on, you can freely combine these components to create various styles.

### Multi-platform Support

CSSGen Editor supports:
- BiliBili - BliveChat@Original Version
- BiliBili - BliveChat@KUMA Modified Version DOM
- YouTube - YouTube Web (Not open yet)
- Twitch - Twitch Web (Not open yet)

and more, we will continue to add more support content, you can easily select the platform and create various styles.
