# Editor Mode

Editor mode provides you with rich style editing functions, in this mode you will be able to adjust all available attributes and details.

## Type Selection

In the top left corner of the preview area, you can select the message type you want to adjust.

<!-- demo:message-type-selector -->

## Message Preview

Below the type selection option is the message style preview for the currently selected type. In the advanced settings mode, you can also select the corresponding layer by clicking on the preview content.

<!-- demo:message-preview -->

> In the advanced settings mode, there will also be a red border displayed on the corresponding layer in the preview when the mouse hovers over the layer.

## Edit Area

### Style Options

Style options contain most of the operations of the editor, you can edit the style here freely.

<!-- demo:operation-list -->

### Message Content Settings

Message content settings area can configure the display content in the preview, you can perform various operations here to preview the display effect of the style under different conditions.

<!-- demo:user-setting -->

> The content in the message content settings will not be saved to the configuration, it will be reset every time you enter the editor.
