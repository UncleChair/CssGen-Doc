# CSS 样式指南

这个章节包含了 CSSGen 提供的所有样式组件的详细说明。

## 样式类别

CSSGen 将样式组件分为以下几个主要类别：

### 📝 文本样式
控制文本的外观，包括颜色、字体、大小、阴影等。

### 🎨 背景样式
设置元素的背景，包括背景颜色、背景图片、渐变等。

### 🔲 边框样式
定制边框的外观，包括边框样式、圆角、阴影等。

### 📐 布局样式
控制元素的布局和排列方式，包括 Flexbox 布局、显示模式、溢出控制等。

## 如何使用

每个样式组件都提供了：

1. **功能介绍** - 组件的主要功能和特性
2. **使用方法** - 如何在代码中使用组件
3. **Props 文档** - 组件接受的属性说明
4. **交互式演示** - 实时调整参数并查看效果
5. **最佳实践** - 使用建议和技巧
