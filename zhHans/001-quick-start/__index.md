# 开始使用 CSSGen 编辑器

欢迎使用 CSSGen 编辑器！本指南将帮助您快速上手，在几分钟内创建您的第一个弹幕样式项目。

## 快速入门流程

使用 CSSGen 编辑器的基本流程如下：

1. **登录注册** - 创建您的 CSSGen 账户并登录
2. **创建项目** - 为您的弹幕样式创建一个新项目
3. **配置样式** - 使用可视化编辑器配置弹幕样式
4. **数据管理** - 管理您的样式数据或导出使用
5. **使用样式** - 在对应的软件中使用您导出的样式

## 前置要求

在开始之前，请确保您已经满足以下要求：

### 账户要求

CSSGen 基于登录状态来管理项目，您需要：

- ✅ 拥有一个账户（如果还没有，请先<a href="/signup">注册账户</a>）
- ✅ 成功登录到系统

### 浏览器要求

CSSGen 基于浏览器运行，并承诺对以下浏览器进行完善的支持：

- **Chrome** - 推荐使用最新版本
- **Safari** - 推荐使用最新版本
- **Edge** (Chromium 内核) - 推荐使用最新版本

> ⚠️ **注意**：在其他浏览器中使用可能会导致兼容性问题，我们强烈建议您使用上述浏览器的最新版本以获得最佳体验。

### 网络要求

- 稳定的网络连接（用于云端同步和加载资源）
