# 定位样式组件

_控制图层在页面中的摆放位置。_

<!-- demo:position-editor -->

> 强制应用选项可以强制覆盖样式设置，通常在某些平台中调整无效时使用。

## 什么是定位

在网页设计中，**定位**<sup><a href="#ref1">[1]</a></sup>决定了图层在页面上的摆放位置和显示方式。就像在纸上摆放照片一样，您可以选择让照片：
- 按顺序摆放（默认方式）
- 相对于原位置移动一点距离
- 固定在纸张的某个位置

通过定位功能，您可以精确控制每个图层的位置，实现各种复杂的页面布局效果。

## 定位方式

定位组件提供了多种定位方式，每种方式都有其特定的用途：

### 无定位（默认）

这是所有大部分图层的默认状态。图层会按照页面的正常文档流排列，就像在文档中依次添加内容一样，大部分图层默认都是无定位的。

**适用场景**：
- 普通的文本段落
- 按顺序排列的列表
- 不需要特殊位置控制的内容

### 相对定位

图层相对于它原本应该出现的位置进行偏移。使用相对定位后，您可以让它向上、下、左、右移动一定距离，但它原本占据的空间仍然保留。

**特点**：
- 图层移动后，原位置仍然被占用
- 不会影响其他图层的位置
- 可作为子图层的定位基点

**适用场景**：
- 需要微调位置但不影响布局的情况
- 作为绝对定位子图层的参考点

### 绝对定位

图层会脱离正常文档流，相对于最近的"定位基点"（非无定位的父图层）进行定位。如果没有这样的父图层，则相对于整个页面定位。

**特点**：
- 完全脱离文档流，不占据空间
- 其他图层会忽略它的存在

**适用场景**：
- 需要精确定位的装饰元素
- 覆盖层或遮罩

## 位置偏移

当图层使用了定位方式（除了"无定位"），您可以通过设置 `锚点` 和 `偏移值` 来精确控制图层的位置：

- **水平锚点**：调整图层在水平方向上的对齐锚点，可选值为 `左侧`、`居中`、`右侧`
- **水平偏移**：调整图层在水平方向上的位置，单位为 `px`
- **垂直锚点**：调整图层在垂直方向上的对齐锚点，可选值为 `顶部`、`居中`、`底部`
- **垂直偏移**：调整图层在垂直方向上的位置，单位为 `px`

## 定位基点

**定位基点**是一个重要概念：当图层的定位方式不为"无定位"时，它会成为其子图层的参考点。

**工作原理**：
1. 子图层使用绝对定位时，会相对于最近的"定位基点"（非无定位的父图层）进行定位
2. 如果父图层是"无定位"，子图层会继续向上查找，直到找到一个定位基点
3. 如果一直找不到，则相对于整个页面进行定位

**实践技巧**：
- 常见做法：给父容器设置"相对定位"，给子元素设置"绝对定位"
- 这样子元素就会相对于父容器定位，而不是整个页面
- 父容器的"相对定位"不设置任何偏移值时，它看起来和"无定位"一样，但可以作为定位基点

## 层级调整

当图层使用了定位方式（除了"无定位"），您可以通过设置 `层级` 来调整图层的层级，绝大部分情况下层级越高，图层越靠前，但需要注意，只有针对同一个定位基点的图层才会互相影响层级<sup><a href="#ref2">[2]</a></sup>。

> 定位是 CSS 中一个非常复杂的概念，很多情况下您需要熟悉 CSS 的定位属性才能更好地使用定位组件。
