# 不透明度样式组件

_不透明度指的是图层的整体不透明度。_

<!-- demo:opacity-editor -->

> 强制应用选项可以强制覆盖样式设置，通常在某些平台中调整无效时使用。

## 数值调整

数值调整可以设置图层的整体不透明度，拖动滑块可以调整。支持的数值范围为 0 到 100，0 表示完全透明，100 表示完全不透明。
