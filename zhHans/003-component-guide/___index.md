# CSS 样式指南

本章节包含了 CSSGen 编辑器提供的所有样式组件的详细说明。

## 样式类别

CSSGen 将样式组件分为以下两个主要类别：

### 📝 基础组件
基础组件提供了一系列预设的快捷操作，可以方便地进行一些通用配置和常用操作。

### 📐 高级组件
高级组件提供了大部分基于 CSS 属性划分的组件，使用时可能需要一些 CSS 基础知识。
