# CSS 样式组件指南

本章节包含了 CSSGen 编辑器提供的所有样式组件的详细说明。

## 样式类别

CSSGen 将样式组件分为以下两个主要类别：

### 📝 通用组件

通用设置下的所有组件被称为 `通用组件`，它们提供了一系列预设的快捷操作，可以方便地进行一些通用配置和常用操作，但一般会有受限的使用和调整范围。

### 📐 高级组件

高级设置下能够在图层设置中进行添加的组件被称为 `高级组件`，它们提供了大部分基于 CSS 属性划分的组件，使用时可能需要一些 CSS 基础知识，但功能更全面，没有使用限制。

> 如果您有兴趣学习 CSS 的一些基础知识，您可以访问 <a href="https://developer.mozilla.org/zh-CN/docs/Web/CSS" target="_blank"> MDN文档</a>了解更多内容。

您可以先了解一些通用组件的使用方法，它们已经可以解决大部分比较简单的样式需求；如果您的需求比较复杂，再尝试了解高级组件的使用方法。或者把所有问题丢给 AI，试试[智能模式](./agent-mode)。
