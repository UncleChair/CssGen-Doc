# 通用组件

在通用设置的选项中您能够看到很多的选项，他们除了名称不同外，很多的功能都比较近似。因此按照功能划分，CSS 编辑器将这些选项分为：

- [布局组件](./layout-component)
- 头像组件
- 边框组件

布局组件能够进行简单的图层显示调整，布局控制以及默认字体设置。

头像组件一般用以设置用户头像以及头像边框，您可以快速地调整头像大小或添加图像边框。

边框组件会对选中区域的边框和背景颜色进行设置，一般用于调整基础的文字显示区域。

通过对通用组件的组合操作，可以满足大部分比较简单的样式需求。
