# CSSGen 文档介绍

欢迎使用 CSSGen！这是一个强大的 CSS 样式生成工具，专为直播平台定制设计。

## 什么是 CSSGen？

CSSGen 是一个可视化的 CSS 样式编辑器，让你可以：

- 🎨 **可视化编辑** - 通过友好的界面实时调整样式
- 🔄 **实时预览** - 所见即所得的编辑体验
- 💾 **样式管理** - 保存和管理你的自定义样式
- 🌍 **多平台支持** - 支持 B站、YouTube 等多个直播平台

## 主要特性

### 1. 丰富的样式选项

CSSGen 提供了全面的 CSS 属性编辑能力：

- **文本样式**：字体、大小、颜色、阴影等
- **背景样式**：颜色、图片、渐变等
- **边框样式**：宽度、颜色、圆角、阴影等
- **布局样式**：Display、Flex 布局等

### 2. 组件化架构

每个 CSS 属性都被封装成独立的组件，便于：
- 模块化开发
- 代码复用
- 维护和扩展

### 3. 用户友好

- 直观的用户界面
- 实时的样式预览
- 简单的导入导出功能

## 快速开始

1. 选择要编辑的元素
2. 在右侧面板中调整样式
3. 实时查看预览效果
4. 保存或导出你的样式
