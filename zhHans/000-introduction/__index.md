# 介绍

了解 CSSGen 是什么，如何从头开始创建弹幕样式，浏览参考案例，交互示例等更多信息。

## 什么是 CSSGen编辑器？

CSSGen 编辑器是一个强大的 CSS 样式生成工具，让你可以：

- 🌐 **在线编辑** - 无需下载安装，随时随地在线编辑
- 🎨 **可视化操作** - 通过友好的界面实时调整样式
- 🔄 **实时预览** - 所见即所得的编辑体验
- 🏭 **样式生成** - 生成可直接使用的样式文本
- 🎯 **多平台支持** - 支持 B站、YouTube 等多个直播平台的多种弹幕软件

## 快速入门

在[快速入门](./quick-start)章节，我们准备了许多示例和具体操作来帮助您快速实现需求，您也可以参考[组件指南](./component-guide)中的进阶内容来了解更多高级功能。

## 为什么选择 CSSGen 编辑器

CSSGen 是为设计师和终端用户设计的易于使用的 CSS 样式编辑器，不需要很多相关的专业知识即可创建多样的弹幕样式。

### 基本免费

CSSGen 编辑器的核心编辑功能都是免费提供的，您可以随时随地在线编辑和预览样式。现阶段云存储相关功能为免费使用，正式版推出后将会缩小免费使用范围并进行阶段性收费以维持服务器成本。

### 功能完善

CSSGen 编辑器提供了丰富的功能，包括：
- 文本样式
- 背景样式
- 边框样式
...

等一系列样式组件，您可以自由组合这些组件来创建多样的弹幕样式。

### 多平台支持

CSSGen 编辑器支持包含：
- BiliBili - BliveChat@原版
- BiliBili - BliveChat@KUMA修改版DOM
- YouTube - YouTube Web (暂未开放)
- Twitch - Twitch Web (暂未开放)

等多个直播平台的多种弹幕软件，并将持续添加更多支持内容，您可以轻松选择平台并创建多样的弹幕样式。
