# 编辑器简介

_初次打开编辑器后，您会进入一个简单的流程指引来帮助您了解编辑器的功能和区块划分，建议您先完成流程指引。_

![编辑器界面](./static/editor.png)

界面主要分为三个区域：

- 系统设置区域： 页面右上角用以进行系统设置和项目数据管理
- 预览区域: 页面左侧用以实时预览当前样式
- 编辑区域: 页面右侧用以进行样式编辑

预览区域和编辑区域的内容将会根据您选择的模式有所不同

## 系统设置区域

您可以在此对项目数据进行管理，或进行系统设置。

### 教程重放

教程重放功能能够重新开始引导教程，界面内容有更新时也会显示提示。

### 同步配置

同步配置会基于云端和本地数据状态决定同步策略。如果您的本地数据比云端的新，则会自动将您的数据上传至云端，如果您的云端数据更新，则会有对话框帮助您决定是覆盖云端数据还是从将云端数据同步至本地。

> 同步配置可能会覆盖您的本地设置，如果您担心数据丢失，可以先进行导出 JSON 备份。

### 主题切换

主题切换功能能够切换编辑器的主题颜色，支持浅色和深色两种模式。

### 语言切换

语言切换功能能够切换编辑器的界面语言。

### 快捷键设置

快捷键设置功能能够打开自定义快捷键的设置对话框，您可以在此进行快捷键设置。

> 部分快捷键例如 `Ctrl + W` 将会被您的浏览器默认行为占用（关闭标签页），请注意这类组合键无法设置；如果您需要使用这类组合键，请先对您的浏览器快捷键进行更改。

### 项目设置

项目设置功能会展开项目相关的操作列表，您可以在此进行项目数据的管理。

#### 上传图片

上传图片选项会打开图片上传对话框，在这里您能够批量管理您的图片资源。

您可以在这里上传本地或在线的图片至编辑器，上传完成后将会自动加载至编辑器供您选择使用。

> 上传或删除图片的操作将不会纳入撤销重做记录，请谨慎操作。

#### 插入全局 CSS

该选项会打开全局 CSS 插入对话框，如果您熟悉 CSS 并想使用一些更高级的属性或写法，可以在这里进行插入。插入后的 CSS 将不会被编辑器纳入管理，但会作为全局样式生效。

> 插入的 CSS 同样不会被纳入撤销重做记录，请谨慎操作。

#### 导入 JSON

导入 JSON 选项能够选择项目配置文件进行导入，导入完成后将会自动加载至编辑器并更新样式。

#### 导出 JSON

导出 JSON 选项能够将项目数据导出为 JSON 配置文件，导出完成后将会自动下载至您的本地文件夹，您可以随时导入该文件以恢复您的项目数据。

#### 导出 CSS

导出 CSS 选项能够将项目数据导出为 CSS 样式文件，导出完成后将会自动下载至您的本地文件夹。

#### 预览并导出 CSS

预览并导出 CSS 选项能够在导出前弹出预览窗口，您可以在此窗口中查看所有编辑的 CSS 样式，并决定是否导出。

### 模式切换

样式编辑器提供了两种模式：编辑模式和智能模式，两种模式下的预览区域和编辑区域内容会有所不同，您可以随时进行切换。

- 编辑模式: 提供了丰富的样式编辑功能，该模式下您将可以详细调整可用的所有属性和细节。<a href="./editor-mode">了解细节</a>

- 智能模式: 接入了 AI 助手的编辑模式，您可以通过下达指令让 AI 助手为您快速调整样式。<a href="./agent-mode">了解细节</a>

> 智能模式仍在开发中，如果您有任何问题或建议，请随时联系我们。
