# 智能模式

_智能模式仍在积极开发中，欢迎您反馈问题和建议。_

智能模式能够通过直接向 AI 助手下达指令来快速调整样式，并支持全局或局部调整模式。

要使用智能模式，您需要先配置 AI 供应商的 API Key 和模型。

## 设置模型

_您的 API Key 将始终被保存在本地，不会上传至我们的服务器，并且仅在使用智能模式时调用。_

目前可用的 AI 供应商包括：

- [Vercel AI Gateway](https://vercel.com/ai-gateway)
- [OpenAI](https://openai.com/)
- [Anthropic](https://claude.com/)
- [Google](https://gemini.google.com/)
- [Ollama](https://ollama.com/)

您可以通过点击聊天框左下角的设置选项弹出的面板进行配置。

<!-- demo:model-select -->

> 本地配置的 Ollama 模型可能因参数问题或硬件性能导致表现不佳，您可以尝试更换模型或使用其他 AI 供应商。

在设置完 API Key 后，您可以在列表中选择您想要使用的模型，模型对应的具体供应商也将显示在选项后方。

## 模式选择

_通过调整模式，您可以控制助手对样式的调整范围。_

|| 全局模式 | 局部模式 |
| --- | --- | --- |
| Token 消耗 | 较高 | 低 |
| 调整速度 | 慢 | 快 |
| 调整范围 | 所有消息类型 | 选中的消息类型 |
| 适用范围 | 整体修改或快速生成全局样式 | 局部调整单一消息样式 |
| 预览内容 | 全部消息类型 | 选中的消息类型 |

## 提示词

配置好模型和模式后，在聊天框中输入提示词来让助手为您调整样式。除了文本内容外，您也可以指示助手使用您添加至项目中的图片或指定您想要使用的图层。

### 使用图片

通过点击聊天框下面的图片选项展开项目图片列表。

> 目前不支持参考图输入功能，您的所有图片都将直接被使用。

### 指定图层

通过点击聊天框下面的 `@` 选项展开图层列表并指定图层。

## 历史消息

_您的所有提示词和回复都将被保存至历史消息列表中，您可以随时查看和编辑。_

### 撤销修改

在发送的每条提示词记录下方都有一个撤销按钮，点击后样式将恢复至该提示词发送前的状态，您可以在聊天框中重新编辑提示词并再次发送。

> 尽管撤销重做快捷键在智能模式下也可以使用，但我们并不推荐，因为智能模式也会修改一些快捷键无法控制的内容，例如全局 CSS 和项目图片。
